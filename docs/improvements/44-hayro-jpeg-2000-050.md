# 44 - hayro jpeg 2000 0.5.0

status: implemented. `hayro-jpeg2000` moves from 0.4.1 to 0.5.0, keeping the
`std` and `simd` features enabled and the `image` feature disabled. The new
release includes a fused SIMD inverse-wavelet path and reconstruction of
region-of-interest shifts. The plugin's JPEG 2000 adapter continues to use the
same public decode calls.

## the change

**`Cargo.toml` and `Cargo.lock`.** Update the dependency version and checksum.
No other dependency changed.

## load-time comparison

Measured on 2026-11-03 on macOS arm64, using the 35 files in `sandbox/jp2`
(32 gray pages and three RGB pages). Both builds use the same optimized plugin
configuration and the same VapourSynth release. Each pass ran in a fresh Python
and VapourSynth process, with baseline and candidate alternating order. Times
cover requesting all 35 frames; clip creation is excluded. The reported values
are medians of three passes per setting.

| `prefetch` | `hayro-jpeg2000` 0.4.1 | `hayro-jpeg2000` 0.5.0 | change |
| ---: | ---: | ---: | ---: |
| 4 (default) | 7.884 s | 7.815 s | 0.9% faster |
| 0 (serial) | 29.492 s | 29.385 s | 0.4% faster |

Both differences are below 1%, so this upgrade does not provide a meaningful
load-time improvement on the current corpus. The timing harness is
`target/bench/ab-hayro-jp2.py`.
